# Oshicolorchart
推しのイメージカラーを、そのままNotionページに落とし込めるツールです。カラーピッカーで色相と彩度・明度を調整しながら、最大4色までパレットに登録できます。
「生成」ボタンを押すと、選んだ4色に名前がつき、配色バーとして一覧表示。
さらに、Notionの数式ブロックで使えるテキスト装飾コード(文字色・背景色・ライン・ドットなど)をチートシート形式でまとめて表示し、ワンクリックでコピーできます。
あとはコード中の「HEX」を好きな色コードに置き換えるだけ。難しい設定は不要で、直感的な操作だけで完結するので、Notionのデザインを自分の"推し色"に染めたい人にぴったりの一本です。
